# User Management Project

Este proyecto es una aplicación básica para gestionar usuarios. Está construido utilizando **Spring Boot** y una base de datos relacional como **H2**, **PostgreSQL** o **MySQL**.

## Características

- Creación automática de la tabla `users` al iniciar la aplicación.
- Inserción de datos iniciales con dos usuarios de ejemplo.
- Configuración sencilla mediante archivos `data.sql`.
- Uso de JPA para la persistencia de datos.

## Requisitos previos

Antes de ejecutar este proyecto, asegúrate de tener instalados los siguientes componentes:

- **Java 11**.
- **Maven 3.6+** en adelante.
- (Opcional) Una base de datos como **PostgreSQL** o **MySQL** si no deseas usar H2.

## Configuración del proyecto

1. Clona este repositorio:
   ```bash
   git clone https://github.com/tu-usuario/user-management-project.git
   cd user-management-project
   ```

2. Configura la base de datos en el archivo `application.properties` o `application.yml`. Por defecto, el proyecto está configurado para usar una base de datos en memoria H2:
   ```properties
   spring.datasource.url=jdbc:h2:mem:testdb
   spring.datasource.driver-class-name=org.h2.Driver
   spring.datasource.username=sa
   spring.datasource.password=password
   spring.jpa.hibernate.ddl-auto=none
   spring.sql.init.mode=always
   ```

   Si deseas usar PostgreSQL o MySQL, actualiza las propiedades correspondientes:
   ```properties
   spring.datasource.url=jdbc:postgresql://localhost:5432/mydatabase
   spring.datasource.driver-class-name=org.postgresql.Driver
   spring.datasource.username=tu_usuario
   spring.datasource.password=tu_contraseña
   ```

3. Asegúrate de que los archivos `schema.sql` y `data.sql` estén en el directorio `src/main/resources/`.

## Ejecución del proyecto

1. Compila y ejecuta la aplicación utilizando **Maven**:
   ```bash
   mvn spring-boot:run
   ```

   O con **Gradle**:
   ```bash
   ./gradlew bootRun
   ```

2. La aplicación iniciará y ejecutará automáticamente los scripts `schema.sql` y `data.sql`.

3. Accede a la base de datos para verificar los datos insertados:
    - Si usas H2, habilita la consola web en `application.properties`:
      ```properties
      spring.h2.console.enabled=true
      spring.h2.console.path=/h2-console
      ```
      Luego accede a `http://localhost:8080/h2-console` e inicia sesión con las credenciales configuradas.

## Scripts SQL

- **Archivo `schema.sql`**: Define la estructura de la tabla `users`.
- **Archivo `data.sql`**: Inserta dos usuarios de ejemplo.

### Contenido de `schema.sql`
```sql
CREATE TABLE users (
    id BIGINT GENERATED BY DEFAULT AS IDENTITY PRIMARY KEY,
    active BOOLEAN NOT NULL,
    email VARCHAR(255) NOT NULL,
    username VARCHAR(255) NOT NULL
);
```

### Contenido de `data.sql`
```sql
INSERT INTO users (active, email, username) VALUES
(true, 'user1@example.com', 'user1'),
(true, 'user2@example.com', 'user2');
```
